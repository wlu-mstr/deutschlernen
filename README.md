# Nicos Weg A1 生词提取工具 + 学习模式

一款配合 **《Nicos Weg A1》** 德语教材使用的本地桌面 GUI 工具，帮学习者在读原文脚本时**精准提取生词**、并按文章顺序**循环复习**。

> Python 3.11 + Tkinter，单文件 GUI，开箱即用。

---

## ✨ 功能

### 📖 浏览 / 提取 标签页

读德语原文时随手记单词：

- **上下文窗口**：当前行 ± N 行可调（±2/4/6/10/20），当前行黄色加粗高亮
- **键盘导航**：`Space` / `PgDn` 大步前进、`Shift+方向键` 单行精调
- **导航按钮**：上一段/下一段（步长 = 当前上下文行数）、上/下移一行、顶部/底部、上一集/下一集、行号跳转
- **提取单词**：鼠标拖选 → `Ctrl+Enter` 自动记录选中的**原文行号**；或一键提取整行
- **生词本管理**：自动去重、列表增删、上移/下移、清空
- **🟢 一键导出**：`💾 保存生词到文件`（绿底醒目按钮）
  - 默认保存到**桌面**，`utf-8-sig` 编码（记事本不乱码）
  - 文件名带时间戳（避免覆盖）
  - 按**原文行号**排序，方便按文章顺序复习
  - 保存后**自动用系统默认程序打开**
- **自动持久化**：每次提取/删除立即写入 `extracted_words.json`，重启不丢

![浏览 / 提取](01%20extract.jpeg)

### 📚 学习模式 标签页

按文章顺序循环复习单词本：

- **左右分栏布局**（可拖动中间分隔条）
  - 左栏：整篇文章渲染，**学习点位置淡黄色高亮**（•），**当前学习点橙色加粗**（▶）
  - 右栏：当前学习点的拆解、释义、句意、动词变位等
- **导航控件**
  - `← 上一个` / `下一个 ⬇`（按**原文行号**顺序走，不是文件顺序）
  - 「按序号跳转」输入框
  - 「跳到浏览页」联动按钮（跳过去同时高亮原文行号）
  - `重新加载` / `选单词本…`
- **🔒 只读单词本**：程序只解析不修改用户手写的单词本文件

## 🚀 启动

### 一键启动（Windows）

双击 `run_extractor.bat` 即可。

### 手动启动

⚠️ **必须使用 `py -3.11`** —— Windows 上只有这个 Python 自带 tkinter：

```powershell
py -3.11 wort_extractor.py
```

如未安装 Python 3.11，可通过 Microsoft Store 安装，或运行：

```powershell
winget install Python.Python.3.11
```

## 📖 单词本格式

每个学习点格式如下（`##` 标题、`###` 子章节、`:`/`：`/` ` 三种行号写法都能识别）：

```markdown
## 1
行号：41
ich bin gut angekommen
### 单词拆解
1. ich：第一人称单数代词，我
2. bin：sein（是/在）第一人称单数现在时变位
### 整体句意
我已经顺利抵达了。
```

要点：
- `##` + 序号：学习点编号（必须从 1 起连续）
- `行号:N` / `行号：N` / `行号 N`：原文行号（中文全角冒号也支持）
- 下一行：单词或短语（会用于「跳到原文行」按钮的目标行号匹配）
- `### xxx`：解释章节，可写任意多个

## 🛠 工具栏说明

### 浏览页底部

| 按钮 | 作用 |
|---|---|
| 删除所选 (Del) | 删除选中行 |
| ↑ 上移 / ↓ 下移 | 调整顺序 |
| 清空全部 | 一键清空列表 |
| **💾 保存生词到文件** | 导出到桌面 txt |

### 快捷键

| 按键 | 行为 |
|---|---|
| `Space` / `PgDn` / `→` | 下一段（步长 = 上下文行数） |
| `PgUp` / `←` | 上一段 |
| `Shift+方向键` | 单行精调 |
| `Ctrl+Enter` | 提取当前选中的词 |

## 🔧 常见问题

**Q：保存按钮在哪？**
A：浏览页底部、紧贴「清空全部」右边，绿底白字的「💾 保存生词到文件」。

**Q：单词本里行号错了怎么办？**
A：程序不会修改你的单词本。运行下面的对齐脚本会生成 `*-aligned.txt`：

```powershell
py -3.11 -c "import sys; sys.path.insert(0,'.'); from wort_extractor import _align_lines"  # 预留入口
```

或者在 Python 里调用 `wort_extractor._align_lines(src, dst)` 自行实现。

**Q：GUI 启动后窗口不显示？**
A：检查是否用了正确的 Python 解释器（必须是 `py -3.11`，其他版本可能没有 tkinter）。
